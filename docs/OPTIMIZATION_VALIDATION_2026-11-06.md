# 优化验证记录（2026-11-06）

基线：`5c4aa8f`。以下为本机验证，不是已部署的生产指标。本次不改变固定模型、生产 ONNX 默认参数或推理并发数。

## 变更

- 已验证的同后端模型状态复用 30 秒，按需后台刷新；状态请求超时 8 秒。保留模型来源校验和后端隔离。
- 普通 SSE 请求不再启动长任务/可见性观察器、分块计量或详细报告构造。显式调试模式保留，控制台仍静默。
- 磁盘缓存 V3 保存紧凑快照，兼容旧 V2 压缩/非压缩缓存；SSE V2 可直接读取紧凑格式，V1/非流 API 保留原结构。
- 可选缓存写回移出响应关键路径，最多两个待写回结果，同键可复用，正常关闭等待写回；强制结束仍可能丢失可重算的缓存。
- SSE 结果 JSON 去除不必要空格，不改变事件前缀和语义。
- 手机状态卡显示简短设备名；主要导航控件触控区域达到 44px；播放按钮修正对比度；牌面添加替代文本，暗牌不泄露牌名。
- 新增有效 `robots.txt`，修正实时 SSE 错误语义文档，更新资源内容指纹。
- ONNX 基准补充硬件/运行时信息和覆盖所有采集决策的 `full_pass`，包含末尾不足批量。

## 缓存对照

同一份线上内置演示结果：4 局、407 个回放步骤。两种缓存均使用 gzip level 3，JSON 使用紧凑分隔符。实际调用缓存读取函数并生成 SSE 结果 JSON，9 次中位数：

| 指标 | V2 完整缓存 | V3 紧凑缓存 |
|---|---:|---:|
| 解压后缓存 JSON | 1,208,616 B | 663,104 B |
| 磁盘文件 | 57,385 B | 46,027 B |
| 读取至 SSE JSON | 55.35 ms | 30.02 ms |

本样本处理耗时下降约 46%，磁盘文件下降约 20%；不代表全站请求耗时下降相同比例，也不包含网络、抓谱及推理。

## ONNX 本机对照

Windows 11，AMD64 Family 23 Model 113，12 个逻辑处理器；Python 3.12.10、ONNX Runtime 1.28.0、NumPy 2.5.1。使用固定 revision/SHA-256 的 Mortal S42 ONNX，对内置演示采集的全部 63 个决策分批推理。每组预热后重复 3 次，表中仅为 `session.run` 累计耗时中位数：

| intra/inter 线程 | batch 16 | batch 64 | batch 128 |
|---|---:|---:|---:|
| 默认 0/0 | 708.55 ms | 764.58 ms | 760.68 ms |
| 1/1 | 1,267.07 ms | 1,211.04 ms | 1,048.30 ms |
| 2/1 | 723.82 ms | 699.49 ms | 690.86 ms |
| 4/1 | 610.65 ms | 564.56 ms | 603.58 ms |

本机最低值比默认线程/batch128 低约 26%。全部配置通过合法 Q 值有限性、非法动作负无穷、Q 值容差（atol/rtol 1e-4）及 argmax 一致性检查。批量上限大于决策数时仍只有一个实际 63 项批次，64/128 的差异主要是测量波动，不能据此认定 64 普遍更优。

**生产参数保持原样。** ModelScope 的 CPU、运行时版本及负载可能不同，需要在生产同规格隔离环境重复对照，不能直接套用本机最佳值。
